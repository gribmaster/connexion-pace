# Connexion Space — Project Rules

## Stack

* Next.js App Router
* TypeScript
* Tailwind CSS
* Prisma
* PostgreSQL
* pnpm

## Architecture

* Keep code simple and modular
* Do not overengineer
* No repository pattern
* No service layer unless explicitly requested
* No unnecessary abstractions

## UI

* Use existing UI components from:

  * @/components/ui/Button
  * @/components/ui/Card
  * @/components/ui/Container

* Mobile-first UI

* Minimal premium design

* Reuse components whenever possible

## Code Style

* Prefer server components unless interactivity is needed
* Use TypeScript strictly
* Keep files small and readable
* Avoid deeply nested logic

## Important

* Do not modify existing UI components unless requested
* Do not install additional packages unless requested
* Do not refactor unrelated code
* Only implement the requested feature

## Workflow

* One feature at a time
* Keep implementation MVP-friendly
